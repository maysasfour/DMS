## 🚀 How to Run

### Prerequisites
- Flutter SDK installed
- Dart SDK 3.0+
- Windows/Mac/Linux development environment
- Connected device or emulator

### Build & Run
```bash
cd c:\Users\HP\downloads\gp1\disaster_management_app

# Install dependencies
flutter pub get

# List available devices
flutter devices

# Run on Windows desktop
flutter run -d windows

# Run on Android emulator
flutter run -d emulator-5554

# Run on Chrome web
flutter run -d chrome
```

### Interactive Commands While Running
```
r - Hot reload (reflect code changes)
R - Hot restart (full app restart)
h - Show all available commands
d - Detach (keep app running)
c - Clear screen
q - Quit app
```

## 🔄 Testing Workflows

### Test Flow 1: Report Incident
1. Login as Citizen
2. Tap "Report Incident" or "+" button
3. Fill incident form (title, description, location, people count)
4. Select severity level (High = orange, Critical = red)
5. Add photos (tap "Add Photos" button)
6. Add video (tap "Add Video" button)
7. Review media in preview grid
8. Remove any media if needed
9. Tap "Submit Report"
10. See success message
11. New incident appears in list

### Test Flow 2: Respond to Incident
1. Login as Responder
2. Go to Incidents tab
3. Filter by "reported" status
4. Tap incident to view details
5. See photos/videos in gallery
6. Tap "Edit" button
7. Change status to "In Progress"
8. Save changes
9. Later change status to "Resolved"
10. Incident moves to resolved section

### Test Flow 3: Admin Overview
1. Login as Admin
2. View Dashboard with stats
3. Check Incidents tab
4. Tap Profile to see Admin Tools
5. See admin-specific action tiles
6. Go to Settings
7. Change language/theme
8. Verify changes apply instantly

### Test Flow 4: Navigation
1. Test all 5 bottom nav tabs
2. Verify each tab loads correctly
3. Switch tabs and verify state
4. Test drawer menu
5. Test navigation back from details
6. Test app bar navigation
7. Verify FAB functionality
